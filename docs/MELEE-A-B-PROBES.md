# Object melee A/B diagnostic experiments

These are manual-melee diagnostic modes, NOT native attack dispatch implementations. Use Mods > DEV > Object Discovery, enable discovery and optionally the laser. Cycle the session-only MELEE PROBES control OFF -> A -> B -> C -> OFF. With the weapon in the right hand, aim the left hand at an untouched grey barrel, hold left Grip, then manually trigger a normal melee (physical punch or normal melee input if enabled). Do not release until the result is visible. Test A and B on separate untouched props, at near and far range; also test a miss and an obstructed prop. Save the normal runtime log and note which objects were hit. Look for [MELEE-PROBE], [MELEE-A], and [MELEE-B].

A logs the offhand aim, head direction comparison, reach and ray-origin proxy candidate. B logs preselected stable native entity/model and vtable RVAs; both correlate manually requested native melee input with same-entity native displacement before normal grab acquisition. Selection is not a collision trace, line of sight, or independent melee contact proof. No extra damage, attack, force, input routing, native memory write or automatic melee is added. A/B are mutually exclusive with C and OFF at startup. Native attack-origin/direction and direct impact ABI must still be independently identified and validated before automatic triggering. Keep ordinary object discovery, calibration and native input unchanged.

## C — ordinary native melee before grab
C is an actual input-level experiment. Enable Object Discovery and C, use right-hand weapon / physical left Grip, face and aim at a fresh grey prop at close native melee distance in an empty test area. Press and hold left Grip once without manually punching. A world-thread proxy selection queues one ordinary 200 ms JOY8 pulse, then the normal grab path may acquire only that same native entity if movement is observed. Already moving targets bypass the wake pulse. No automatic retry while held; release Grip to rearm. No extra force, fake collision, damage/animation edits or new native attack ABI. DOOM controls native attack direction and range; offhand proxy selection is not proof of line of sight or actual attack contact and this regular melee can hit a different object in its path. Logs [MELEE-C] report queue, pulse, cancellation, timeout, and native hold confirmation. A/B remain manual probes. Runtime validation pending.
