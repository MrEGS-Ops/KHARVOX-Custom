Comparison test events report explicit observed outcomes, not blanket success. Tests remain read-only and are rate limited; a fresh level invalidates the test permissions. For release, compare displacement-derived acceleration with gravity; for collision, compare candidate clip bounds against the hand ray; for activation, record native motion and the pre/post rest field; for movement, sample native position change; for ledge, observe native active state/transition. These are evidence tests, not custom gameplay implementations.
