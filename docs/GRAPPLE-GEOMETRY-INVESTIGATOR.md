# Grapple geometry investigator
Automatically runs on a new Grip press with Grapple Grab enabled, including a miss. No additional menu or persistent settings. Use a quiet area, try small and large props at different angles, include misses, and release Grip between attempts. Send the full runtime log. Search [GEOMETRY-INV].
Records: hand and ray transforms, all nearby candidate ranking up to 16, origin depth/miss/distance, motion/freshness, selected native object identity, class and model path, pointer links and embedded polymorphic objects, vtable function RVAs, bounded raw object windows, plausible array count/capacity and sample bytes, candidate AABBs, actual acquired handle, local offset/axis and proxy contact. No speculative function invocation or physics writes. Candidate arrays and bounds are NOT validated geometry. Per dump cap: 24 nodes, three hops, 32 KiB raw, 48 bounds, 24 arrays, 35 ms best-effort time budget (individual reads/log writes can exceed it); at most two dumps per Grip. May cause a brief hitch and logs can be large. ReadProcessMemory is limited to current process, selected object-associated readable memory. The object allocation size is not yet known, so raw windows may contain adjacent data. Logs contain process-local addresses; don't post publicly unless redacted. No visual overlay in this revision; runtime geometry provider and exact surface contact remain unverified.
